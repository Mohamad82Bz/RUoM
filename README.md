# RUoM

> [!WARNING]
> **RUoM is no longer maintained. Please use [StickyNote](https://github.com/sayan-development/stickynote) instead.**
> StickyNote is a Kotlin framework for bukkit plugin development bundled with all the features of RUoM and a lot more.

# What is RUoM
RUoM is a Minecraft plugin library that is packed with some utilities and libraries like Adventure, XSeries and more.
The motivation behind this project was to provide tools to make plugin development easier by reducing boilerplate code and allowing developers to focus on the plugin itself.
